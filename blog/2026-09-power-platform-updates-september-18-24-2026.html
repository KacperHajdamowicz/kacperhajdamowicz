Power Platform Updates (September 18 - 24, 2026)

25 Sep 2026

Most of this week is Power Pages and Microsoft Foundry. Power Pages gets free managed certificates for custom domains, and Modern List leaves preview. Foundry gets egress rules for hosted agents, and routines go GA. All of it is available now, preview or GA, so you can try each item in a tenant this week.

Egress controls for Microsoft Foundry agents

Egress controls for hosted agents are in preview. You write outbound rules in an RAI policy and attach it to the agent container, and the platform blocks requests to domains outside the list. Until now the only place to stop an agent tool from calling an unapproved host was the tool's own code. An audit mode lets you run permitted and denied probes against the rules before you switch to blocking.

https://devblogs.microsoft.com/foundry/egress-controls-hosted-agent/

Microsoft Foundry routines reach general availability

Routines are GA in Foundry Agent Service. Before, an agent that had to run on a timer or react to an event needed your own scheduler or listener next to it. Now you set that up on the agent itself: run on a schedule, or wake up on an external event such as a new Teams message. There is also a reminder tool. An agent that is waiting on a slow external process can stop, set a reminder, and pick up again later.

https://devblogs.microsoft.com/foundry/from-chatbots-to-automated-assistants-routines-in-microsoft-foundry-are-now-generally-available/

Default managed certificates in Power Pages

Custom domains on Power Pages used to mean buying a certificate and renewing it yourself. Nick Doelman spotted that Microsoft now issues a free SSL certificate for a custom domain and renews it automatically. You pick it in the Power Platform admin center while setting up the domain. One catch: the option only shows up with CDN and WAF turned off, so disable both for the setup and turn them back on after.

https://readyxrm.blog/2026/09/18/free-ssl-tls-certificates-for-power-pages/

Modern List goes to general availability

Modern List is GA and is now the default list for Dataverse records on new Power Pages sites. It is built on Fluent UI and has infinite scrolling. There is a Client API, so custom JavaScript can read raw cell values and change column formatting without replacing the whole list with your own grid. Existing sites keep their classic lists, so nobody is forced to migrate on a date.

https://www.microsoft.com/en-us/power-platform/blog/power-pages/modern-list-in-power-pages-is-now-generally-available/

Invoking cloud flows from Server Logic

Server Logic in Power Pages, the server-side place for business rules, can now call Power Automate cloud flows. If a site action starts something bigger, say notifying a third-party system, you hand it to a flow and let an existing connector do the work. The page does not wait on the integration, and you do not rebuild in Server Logic what the flow already does.

https://www.microsoft.com/en-us/power-platform/blog/power-pages/extend-server-logic-with-power-automate-cloud-flows-in-power-pages/

Building human-in-the-loop workflows

Matthew Devaney has a walkthrough on pausing a Copilot Studio agent to ask a person. The agent sends a message over Teams or email, waits for a structured answer, and branches on it. Use it wherever an agent reaches a decision you would not let it make alone; the risky branch then only runs after someone has said yes.

https://www.matthewdevaney.com/video-copilot-studio-add-human-review-to-your-ai-agents/
