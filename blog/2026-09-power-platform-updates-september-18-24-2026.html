Power Platform Updates (September 18 - 24, 2026)

September 2026

Microsoft published several highly practical updates for Power Pages and Microsoft Foundry this week. Administrators handling external-facing sites will appreciate the shift to managed certificates alongside finalized list controls. Developers working on AI agents gained concrete ways to restrict network access and schedule background tasks. This round avoids conceptual announcements and focuses on core infrastructure changes you can use right away.

Egress controls for Microsoft Foundry agents

Microsoft introduced a preview feature granting finer control over where hosted agents can send network requests. You define explicit outbound rules via an RAI policy and attach them to your agent container. This removes the need to rely entirely on code-level checks inside the agent tools to prevent connections to unapproved domains. A companion audit mode lets you run permitted and denied probes to verify the network boundary before strictly blocking traffic.

https://devblogs.microsoft.com/foundry/egress-controls-hosted-agent/

Microsoft Foundry routines reach general availability

Building an automated agent that responds to events previously required running your own schedulers and event listeners. The new routines feature moves that infrastructure directly into the Foundry Agent Service. You choose to configure an agent to run on a scheduled basis or react immediately to external events like new Microsoft Teams messages. A reminder tool also lets an active agent pause its work and schedule its next execution if it has to wait for a long external process to finish.

https://devblogs.microsoft.com/foundry/from-chatbots-to-automated-assistants-routines-in-microsoft-foundry-are-now-generally-available/

Default managed certificates in Power Pages

Getting a custom domain running on Power Pages historically involved buying a certificate and managing renewals manually. A quiet update highlighted by Nick Doelman changes this workflow. Microsoft now issues and automatically renews free SSL certificates for custom domains. You configure this entirely in the Power Platform admin center during domain setup. You do need to temporarily disable your Content Delivery Network (CDN) and Web Application Firewall (WAF) before the option becomes visible.

https://readyxrm.blog/2026/09/18/free-ssl-tls-certificates-for-power-pages/

Modern List goes to general availability

The Modern List component in Power Pages is the new default control for displaying Dataverse records on all fresh sites. It replaces the classic list presentation with Fluent UI components and infinite scrolling out of the box. Developers get access to a Client API to manipulate the grid with custom JavaScript. You read raw cell values and change column formatting programmatically without dropping down to a completely custom data grid. Classic lists will stay active on existing portals so migration can happen gradually.

https://www.microsoft.com/en-us/power-platform/blog/power-pages/modern-list-in-power-pages-is-now-generally-available/

Invoking cloud flows from Server Logic

Power Pages Server Logic gives developers a secure backend environment for running business rules. Microsoft extended this pattern by adding support for triggering Power Automate cloud flows directly from that code. When a website interaction kicks off a larger business process like sending notifications to third-party systems, you simply pass the event off to a flow using an established connector. This keeps the client responsive and avoids duplicating complex integration logic your organization already built inside Power Automate.

https://www.microsoft.com/en-us/power-platform/blog/power-pages/extend-server-logic-with-power-automate-cloud-flows-in-power-pages/

Building human-in-the-loop workflows

Autonomous agents consistently hit situations they cannot safely handle alone. Matthew Devaney created a technical walkthrough demonstrating how to pause a Copilot Studio process to ask a human reviewer for guidance. The agent sends a targeted message via Teams or email, waits for a structured response, and uses that decision to pick its next action. This specific pattern isolates risky automated choices and ensures sensitive branches only proceed under direct supervision.

https://www.matthewdevaney.com/video-copilot-studio-add-human-review-to-your-ai-agents/
