Power Platform This Week: September 1-7, 2026

8 Sep 2026

The canvas authoring agent plugin for Power Apps is GA. That is the one product change this week that actually matters if you build canvas apps. Microsoft is also pushing Power Platform Community Conference as the place they will talk through the 2026 roadmap, and Matthew Devaney published a usable multi-agent Copilot Studio pattern.

Canvas authoring agent plugin goes GA

The plugin left preview on September 1. You describe a change in plain language and the agent edits the canvas. It works on apps you already maintain, not only new ones. If you kept people off preview, you now have a supported path. If you run a CoE, this is the point where you write it into the process instead of treating it as a trial.

https://www.microsoft.com/en-us/power-platform/blog/power-apps/turbocharge-your-canvas-development-with-the-canvas-authoring-agent-plugin-now-generally-available/

PPCC 2026 is the calendar item

Microsoft framed PPCC 2026 as the event where they talk AI against existing processes, and published a session preview. Nothing shipped because of that post. For people who track the platform, the session list is still the early signal of the next few quarters. The 2026 emphasis is agentic workflows, which matches the last year of releases.

https://www.microsoft.com/en-us/microsoft-365/blog/2026/09/03/ppcc-2026-bringing-ai-and-your-business-processes-together/

Multi-agent workflows in Copilot Studio

Matthew Devaney walked through one task split across three Copilot Studio agents, each narrower, running in parallel. Copy it if a single agent has started to sprawl. Narrower agents usually give cleaner output and the work can overlap.

https://www.matthewdevaney.com/video-multi-agent-workflows-in-copilot-studio/

No platform-defining announcement this week. The canvas plugin going GA is the change on the books. The rest is a conference calendar and a community pattern. Fine.
