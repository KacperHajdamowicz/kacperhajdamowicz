Power Platform: September 18, 2026

September 2026

This week brings major infrastructure and tooling updates across Power Platform and Microsoft Foundry. Microsoft expanded Power Platform CLI with over 200 auto-generated API commands, released a unified setup installer for Foundry developers, published backend engineering lessons from Copilot Studio's migration to Azure Managed Redis, and community experts shared design patterns for multi-agent workflows. Here is what changed and what it means for your implementation strategy.

Auto-Generated Power Platform API Commands Arrive in PAC CLI

Microsoft released a public preview of auto-generated command groups in Power Platform CLI (PAC CLI). The CLI now generates commands directly from the monthly Power Platform API specification, adding 15 namespaces and more than 200 commands covering licensing, governance, environment lifecycle, Copilot Studio, and workflow agents. Developers can also run pac auth token to fetch bearer tokens for newly deployed REST endpoints before CLI updates land.

https://devblogs.microsoft.com/powerplatform/power-platform-cli-%e2%9d%a4%ef%b8%8f-power-platform-api/

Foundry Dev Pack Consolidates AI Tooling Setup

Microsoft launched the Foundry Dev Pack, an installer that sets up local environments for Microsoft Foundry development. Operating system package managers like winget or Homebrew can now install Azure CLI, Azure Developer CLI, the Foundry extension, VS Code extensions, and coding agent skills in a single command. This eliminates manual dependency tracking when configuring developer workstations or CI environments for agent building.

https://devblogs.microsoft.com/foundry/foundry-devpack-announcement/

Copilot Studio Infrastructure Lessons from Azure Managed Redis Migration

The Copilot Studio engineering team detailed their backend migration from Azure Cache for Redis Classic to Azure Managed Redis. By eliminating redundant cache writes and placing local in-memory L1 checks before distributed queries, the team dropped cache server load from up to 95 percent down to 15 to 40 percent. The architecture breakdown provides practical caching patterns for high-throughput agent workflows and enterprise connectors.

https://devblogs.microsoft.com/powerplatform/azure-managed-redis-migration/

Building Multi-Agent Workflows in Copilot Studio

Matthew Devaney published a guide on structuring multi-agent architectures inside Copilot Studio. The tutorial walks through splitting complex tasks across specialized parallel agents, combining deterministic JSON rule evaluation with agentic document extraction and SharePoint knowledge retrieval. This approach increases execution speed and output accuracy compared to single-agent prompts.

https://www.matthewdevaney.com/how-to-build-multi-agent-workflows-in-copilot-studio/
