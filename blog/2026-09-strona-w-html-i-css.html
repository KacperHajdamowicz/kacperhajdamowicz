Strona osobista w czystym HTML i CSS

wrzesień 2026

To trzecia wersja mojej strony. Poprzednia miała React, Vite, animowany gradient na WebGL i karty ze szkła. Wyglądała dobrze, ale żeby zmienić jedno zdanie, trzeba było odpalić npm run dev, a żeby opublikować, poczekać na build w GitHub Actions.

Ta wersja to cztery pliki HTML i jeden arkusz CSS. Zero JavaScriptu, zero zależności. Otwiera się podwójnym kliknięciem, publikuje przez git push.

Skąd pomysł

Wzorem była strona Tani Rascii, tania.dev: nagłówek, treść na 760 pikselach, krótka oś czasu zamiast długiego „o mnie", lista wpisów jako zwykłe wiersze. Wziąłem układ i rozwiązania techniczne, zmieniłem kolory, kroje i sekcje pod to, czym się zajmuję.

Co jest w środku

Landing z osią czasu i zdjęciem, CV w HTML z osobnym stylem do druku, przycisk do Calendly (zwykły link, żaden widget) i ten blog. Nowy wpis to kopia szablonu i jedna linijka na liście.

Na co dzień buduję rzeczy na Power Platform, więc tu będą notatki o Power Apps, Power Automate, Dataverse, Copilot Studio i o tym, co się psuje przy ALM. Krótko, bo długie wpisy i tak nikt nie czyta do końca.
